Shin Gundam Musou English Patcher Experimental

English patch for 真・ガンダム無双 (PS Vita, PCSG00278), game version 1.00 or 1.02.

Your files never leave your computer. Patching runs entirely in this browser tab; nothing is uploaded. This web patcher is experimental. If it fails, use the manual install with Delta Patcher. Works best in desktop Chrome or Edge; it needs about 2 GB of free memory.

1. Get the files from your Vita

  • eboot.bin.elf: decrypt the game's eboot.bin with FAGDec (START DECRYPT (ELF)). For 1.00 use ux0:app/PCSG00278/eboot.bin, for 1.02 ux0:patch/PCSG00278/eboot.bin.
  • LINKDATA.B and LINKDATA.C: in VitaShell open ux0:app/PCSG00278/ with Open decrypted (△ menu) and copy them from LINKDATA_NGP/.

Step-by-step instructions are in the README.

2. Choose the three files

Drop the files here, or

  • eboot.bin.elf
  • LINKDATA.B
  • LINKDATA.C

3. Patch and save

Saving to a folder writes rePatch/PCSG00278/… inside the folder you pick, without building a 1 GB zip first.

4. Copy to your Vita

Copy the rePatch folder to the root of ux0: on your Vita (for the zip, unzip it first), so you end up with:

ux0:rePatch/PCSG00278/eboot.bin
ux0:rePatch/PCSG00278/LINKDATA_NGP/LINKDATA.B
ux0:rePatch/PCSG00278/LINKDATA_NGP/LINKDATA.C

You need the rePatch plugin installed. Start the game, and it's in English.
